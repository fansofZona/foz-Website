Every project on this site starts in the same place: a scraper hitting a
public source, a schema that fights back, and a warehouse that says "no" to
the next six sports. This tool is all three in one repo.

It is deliberately boring software. Politely rate-limited, cached, resumable,
and re-runnable from scratch. We normalize scores, lineups, and event logs
across six sports into one star schema so a cross-sport question can live in a
single SQL query.

## Why you want this instead of an API

APIs break, panels throttle, and someone always wants the 2019 archive. A
deterministic scraper with a versioned schema survives all three. We keep the
raw HTML and the parsed rows in the same warehouse, so when the scraper is
wrong — and it was, badly, three times this season — the original source is
one table away.

The repo has the dockerfile, the tests, and an honest `KNOWN_ISSUES.md` that
grows faster than we delete from it. Clone it, point it at your data, and
print something.
